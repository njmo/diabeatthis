# DiaBeatThis — poradniki użytkownika

DiaBeatThis pomaga planować posiłki i aktywności, korzystać z przypomnień oraz
przeglądać historię. Obliczanie, potwierdzanie i podawanie insuliny pozostaje
po stronie użytkownika i AAPS. Aplikacja nie podaje insuliny automatycznie.
