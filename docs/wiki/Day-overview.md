# Podsumowanie dnia

Widok dnia zbiera dostępny kontekst glikemii, insuliny, posiłków i aktywności.
Zwykłe podsumowanie nie wymaga uruchamiania analizy AI.

## Jak z niego korzystać

1. Otwórz podsumowanie dnia i wybierz interesującą datę.
2. Sprawdź czas aktualizacji i informację o kompletności danych.
3. Przejrzyj części dzienną i nocną glikemii oraz dostępne dane o insulinie.
4. Zobacz posiłki i aktywności zapisane w tym dniu.
5. W razie potrzeby przejdź do szczegółów konkretnego posiłku lub aktywności.

Brak zdarzenia w podsumowaniu nie potwierdza, że nie wystąpiło — sprawdź źródło
danych i synchronizację. Pobranie nowych danych wymaga połączenia ze źródłem;
wcześniej zapisane dane lokalne pozostają dostępne.

## Tryb opiekuna

W planowanym trybie rodzinnym podsumowanie dotyczy udostępnionych danych dziecka.
Opiekun przegląda stany wykonania bez ich zmieniania. Aktualny konfigurator
jest demonstracyjny i nie uruchamia jeszcze połączenia z dzieckiem.
